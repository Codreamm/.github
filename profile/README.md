# 확장형 자격증 문제 풀이 플랫폼
여러 자격증의 문제를 하나의 플랫폼에서 풀고, 학습 기록과 오답을 관리할 수 있는 **확장형 문제 은행 서비스**입니다.

## 기획 개요

| 항목 | 내용 |
| --- | --- |
| **서비스 유형** | 웹 기반 자격증 문제 풀이 및 학습 서비스 |
| **주요 사용자** | 자격증 시험을 준비하는 학습자 |
| **핵심 가치** | 문제 풀이, 오답 복습, 학습 진도 관리 |
| **초기 대상** | 정보처리기사, SQLD, 정보처리산업기사, 컴퓨터활용능력 |
| **핵심 방향** | 다양한 자격증을 유연하게 추가할 수 있는 공통 문제 은행 구축 |

## 기획 배경

- **분산된 학습 환경 개선**: 여러 자격증의 문제를 하나의 플랫폼에서 학습할 수 있도록 합니다.
- **체계적인 문제 관리**: 자격증, 시험, 과목, 회차별로 문제와 해설을 일관되게 관리합니다.
- **반복 학습 지원**: 오답 노트와 북마크를 활용해 취약한 문제를 반복 학습할 수 있도록 합니다.
- **학습 성과 가시화**: 정답률과 풀이 기록을 통해 학습 진행 상황을 확인할 수 있도록 합니다.
- **확장 가능한 구조 설계**: 신규 자격증 추가 시 기존 문제 풀이 로직을 최대한 재사용할 수 있도록 설계합니다.

## 핵심 서비스 기능

### 1. 자격증 및 문제 관리
- 자격증별 시험 및 과목 분류
- 연도·회차별 문제 조회
- 문제, 보기, 정답 및 해설 관리
- 신규 자격증 추가 지원

### 2. 문제 풀이
- 객관식 및 복수 정답형 문제 풀이
- 답안 제출 및 자동 채점
- 정답 여부와 해설 확인
- 학습 모드 및 시험 모드 지원

### 3. 오답 노트 및 북마크
- 오답 문제 자동 저장
- 오답 문제 모아 풀기
- 중요 문제 북마크
- 문제별 풀이 기록 확인

### 4. 학습 통계
- 자격증별 정답률 및 풀이 현황
- 과목별 성취도 확인
- 최근 학습 내역 조회
- 취약 영역 파악 및 반복 학습 지원

### 5. 관리자 기능
- 자격증·시험·과목 관리
- 문제 등록·수정·삭제
- 정답 및 해설 관리
- 문제 공개 상태 및 데이터 검증

## Tech Stack

| **분류** | **기술** | **역할** |
|---|---|---|
| Frontend | Next.js, React, TypeScript | 사용자 인터페이스 구현 |
| Styling | Tailwind CSS | UI 스타일링 |
| Backend | Java, Spring Boot | REST API 및 비즈니스 로직 |
| ORM | Spring Data JPA | 데이터 접근 및 객체-관계 매핑 |
| Database | PostgreSQL | 자격증, 문제 및 학습 기록 관리 |
| Security | Spring Security | 인증 및 권한 관리 |
| Testing | Vitest, React Testing Library, JUnit 5 | 프론트엔드 및 백엔드 테스트 |
| Container | Docker | 백엔드 실행 환경 표준화 |
| Frontend Error Monitoring | Sentry | 프론트엔드 오류 수집 및 추적 |
| Backend Logging | SLF4J, Logback | 백엔드 로그 기록 및 레벨 관리 |

## Infrastructure & Deployment

| **분류** | **기술** | **역할** |
|---|---|---|
| Frontend Hosting | Vercel | Next.js 배포 및 자동 배포 |
| Backend Hosting | Amazon EC2 | Spring Boot 애플리케이션 실행 |
| Database | PostgreSQL | 서비스 데이터 저장 |
| CI/CD | GitHub Actions | 빌드, 테스트 및 배포 자동화 |
| Log Management | AWS CloudWatch Logs (확장 예정) | 백엔드 로그 수집, 검색 및 관리 |
| Monitoring | AWS CloudWatch (확장 예정) | 서버 및 애플리케이션 모니터링 |
| Object Storage | Amazon S3 (확장 예정) | 이미지 및 파일 저장 |
